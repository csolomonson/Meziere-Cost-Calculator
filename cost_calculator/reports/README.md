# Retired Crystal Reports assets

The production application no longer reads `.rpt` files. The internal cost-audit
and customer-safe PDFs are generated by `reporting/reportlab.py` inside the Python
application container.

This directory is retained only to avoid deleting historical, uncommitted report
design work during the Ubuntu migration. It is excluded from the production image.
